Entry for the [Famous Last Words: The Funniest Epitaph](https://make.fun/bounty/u-riidzhsn-famous-last-words-the-funniest-epitaph-ff177406) bounty on make.fun.

The program writes a single one-line tombstone epitaph — the funniest possible
famous last words, at most 150 characters — to `/output/entry.txt`.

## Run

```sh
node main.ts
```

It writes `/output/entry.txt` containing:

> “Spell it right,” I told the stonecutter. He carved “Spell it rite.” Now I’m dead and still correcting him.
